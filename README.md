# Agentic AI for Trustworthy Engineering Design

Website for the NSF collaborative research project **Agentic AI for Trustworthy Engineering Design**, led by Penn State and the University of Michigan.

## Website

The public site is hosted with GitHub Pages at:

<https://agenticaifordesign.github.io/>

## Local preview

From this directory, start a static file server:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Structure

- `index.html` contains the page content and structure.
- `styles.css` contains the responsive visual design.
- `assets/` contains the project figure, logos, and team photographs.
- `.nojekyll` tells GitHub Pages to serve the static files directly.
